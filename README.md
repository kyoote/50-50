# 50:50

HTML・CSS・JavaScriptのローカル地理ゲーム。経度の縦線を動かし、表示された地図の左右の統計量を50:50に分けます。1ゲーム5問です。

## 起動

フォルダー全体を保存し、`index.html` をChromeまたはEdgeで開いてください。プレイにPython・インストール・ネット接続は不要です。`data/bundle.js` を同じフォルダー構成で保持してください。

ローカルサーバーを使う場合は、このフォルダーで `python -m http.server 5050 --bind 127.0.0.1` を実行し、`http://127.0.0.1:5050` を開きます。

## ルール

タイトル画面は左に球体の地球、右にタイトルとモードを表示します。スマートフォンでは縦に並びます。カメラは地球の中心を向いたまま約30秒で一周し、ドラッグ・タッチ・矢印キーで視点を変更できます。手を離すと約1.2秒かけて自動周回の速度に戻ります。地球の下のボタンで停止・再開できます。端末の「動きを減らす」設定時は停止した状態で開始します。

地球は収録済みNatural Earthの実形状を球面へ貼り付け、標準WebGLで描画します。追加ライブラリや外部通信はありません。WebGL非対応時は軽量なCanvas描画へ切り替えます。ゲーム中・タブ非表示中は地球の描画を休止します。

- 日本：日本列島を固定表示。人口・樹木被覆・農地・市街地・草地・水面・低木地・湿地・裸地・岩場・降水の10指標。
- 世界：中心の経度を問題ごとに変更。人口・建物被覆・陸地・海洋と降水19期間の計23種類。
- ランダム：日本と世界を混ぜます。
- 世界は経度のみ、日本は経度・緯度をランダムに出題。クリック、タップ、ドラッグ、スライダー、矢印キーで経度では縦線、緯度では横線を動かします。
- 世界地図の左端から回答線までの累積量で採点します。日付変更線は自動的に折り返します。表示の中心が変われば正解も変わります。
- 指標は一巡するまで重複せず、その後は再出題します。日本は10指標から異なる5問を出題します。世界では指標が同じでも中心位置を変更します。
- 回答前は比率を表示しません。回答後は回答の実線と正解の破線、左右比率・誤差・得点・星を表示します。

|日本人口|同上、日本専用constrainedグリッド|2025|3秒（約100m）|CC BY 4.0|
|日本の樹木被覆・農地・市街地・草地・水面|[ESA WorldCover v200](https://esa-worldcover.org/en/data-access)|2021|10m|CC BY 4.0|
|日本の降水|[CHIRPS v3](https://chc.ucsb.edu/data/chirps3)|2025|0.05°|提供元記載CC BY 4.0 / public domain|
|世界の降水|[GPCP v2.3 / NOAA PSL](https://www.ncei.noaa.gov/products/global-precipitation-climatology-project)|2025|2.5°|NOAA公開データ・出典表示|

世界地図：[Natural Earth](https://www.naturalearthdata.com/) 1:50,000,000、public domain。日本境界：[geoBoundaries gbOpen JPN ADM0](https://www.geoboundaries.org/api/current/gbOpen/JPN/ADM0/)、原典は国土数値情報2022年、CC BY 4.0。表示のみ位相を保持して簡略化し、集計は元境界を使用します。

人口はモデルによる推計値です。土地被覆は日本境界内の約99.97%をカバーし、小笠原等の4未配布タイルとNoDataを補完せず除外しています。樹木被覆は法令上の森林面積とは異なります。日本の降水は陸域で約99.967%の有効面積率。世界の降水は海洋・極域・雪の水当量を含み、2025年は暫定値です。

森林・農地の世界版、夜間光、CO₂は未収録です。JRC人口も候補として取得しましたが、最終版は取得・検証できたWorldPopを採用しています。架空分布はありません。

世界の陸地面積はNatural Earthの元の国別ポリゴンを球面等積座標に変換して重複を統合し、0.05°帯と交差させて計算します。南極を含みます。原図の湖などの穴の表現に従うため、厳密な陸水分離ではありません。地図は1:50,000,000の海岸線であり、細かい島や海岸線には限界があります。

市街地は人工被覆であり行政上の都市区域ではありません。草地は草本被覆、水面は年の大半を水が覆う湖・貯水池・河川などで、日本境界内のみを対象にします。

## 前処理・再生成

プレイには不要です。データを再生成する場合だけPython 3.12と`requirements.txt`のライブラリを使用します。元データは約1GB、処理用に数GBの空きを確保してください。配布サーバーによってダウンロードに時間がかかります。

```powershell
python -m pip install --target work/python -r requirements.txt
python download_data.py --raw work/raw --deps work/python
python generate_data.py --raw work/raw --deps work/python --workers 4
node test_game.cjs
```

実行並列数は論理CPU数−1と4の小さい方が上限です。内部BLASは1スレッド。大きな人口ラスタは256行ずつ読み、4並列で行・列合計します。ブラウザーでGeoTIFFを処理しません。

- 人口：元グリッドの全有効セルの人口をそのまま加算。日本はWorldPopの国別ファイルを使います。
- 土地被覆8指標：日本と交差する29タイルを10mのまま集計。日本境界内のセル中心を採用し、class 10 / 40 / 50 / 30 / 80 / 20 / 90 / 60 のセル面積を緯度別の球面面積で重み付けします。
- 日本降水：年間mm×日本境界とセルの交差面積÷1000でm³。海岸線を含む交差面積は球面等積変換で計算します。
- 世界降水：月平均mm/day×暦月の日数×球面セル面積÷1000。2025年の12か月を確認して合計します。
- NoData、負値、非有限値を除外し、推測で埋めません。セル内は一様と仮定し、累積分布を線形補間します。
- 各JSONは元解像度の経度・緯度別分布、累積和、メタデータを保持します。日本の緯度問題では緯度別累積和を使用し、南側（下側）の割合を最初に表示します。
- `bundle.js`では等間隔座標と分布から累積和を復元し軽量化します。人口は小数6桁、面積・体積は小数3桁で保存。全帯域の累積相対誤差が1e-7未満であることを生成時に確認し、間引きはしません。

世界の左端をL、回答をxとし、元の累積割合Fを360°周期で延長したCに対して `p=C(x)−C(L)` と計算します。正解は `[L,L+360]` 内でp=0.5になる位置。描画も元ポリゴンを±360°複製して表示区間で切り取り、採点と同じ経度区間を使います。

## スコア・星

誤差 `d=|100p−50|`。得点は `round(1000×exp(−d²/(2σ²)))`、`σ=10/√(2ln2)`。誤差10ポイントで500点です。

星の誤差上限は、★10から★1の順に `0.5, 1, 2, 5, 7.5, 10, 15, 20, 30, 40` ポイント。それ以上は★0。総合星は5問の星の平均を四捨五入します。一般プレイヤーによる難易度調整は未実施です。

## 検証

`validation.json` に総量・未配布タイル・有効面積・元グリッド直接合計との比較・軽量化誤差を記録しています。世界人口約81.954億人、日本人口約1.234億人。これは当該WorldPopファイルの総量です。

自動テストは、中央値・端点・累積単調性・得点・星・300ゲームの出題順に加え、7つの地図中心における回転後の累積量を元の経度帯の重なり面積から直接積分して比較します。

## 指標を追加する場合

実グリッドを取得し、単位と日本の領域マスクを確認してから `generate_data.py` の `save_metric` 形式でJSONを生成してください。出典・年・解像度・ライセンス・処理方法・欠損処理を記録し、総量と分布を検証します。`game.js` の指標名一覧に表示名を追加し、bundleを再生成します。未取得データを出題用に補完しないでください。

## URLで公開する場合

静的サイトとして公開できます。配信に必要なのは `index.html`、`style.css`、`game.js`、`globe.js`、`data/bundle.js` です。出典の説明用にこのREADME、DATA_SOURCES.md、validation.jsonも同梱できます。Python、元GeoTIFF、work/は公開不要です。静的ホスティングに配置すれば、そのURLで同じゲームを利用できます。この版では外部公開していません。

公開用の `50-50-web.zip` は、展開した直下にindex.htmlがある構成です。ZIPを展開し、その中身を静的ホスティングの公開フォルダーへ配置します。ビルド処理・APIキー・サーバー処理は不要です。ローカルでは展開後のindex.htmlをブラウザーで開いて遊べます。

追加指標：低木地はclass 20、湿地は草本湿地class 90（マングローブ等は別分類）。海洋は原図の陸地の補集合で、原図で除外された湖等も含みます。期間別降水は2025年の各月12種類、1〜3・4〜6・7〜9・10〜12月の4種類、1〜6・7〜12月の2種類、年間1種類の計19種類です。旧3か月合計2種類は出題から除外しました。既存のGPCP月別データを暦日数・球面面積で重み付けします。


降水は期間数で抽選確率が増えないよう、地域・指標グループを先に抽選してから期間を選びます。月別・四半期別・半期別の各経度帯と緯度帯の合計が年間分布に一致することをテストしています。

追加データ：世界の建物が覆う面積は[JRC GHS-BUILT-S R2023A](https://human-settlement.emergency.copernicus.eu/ghs_buS2023.php)、2020年、30秒（約1km）、CC BY 4.0。Pesaresi & Politis (2023)、DOI:10.2905/9F06F36F-4B11-47EC-ABB0-4F8B7B1D72EA。各セルのm²をそのまま合計し、延べ床面積とは区別します。日本の裸地・岩場はESA WorldCover class 60（植生が非常に少ない土地を含む）です。
建物被覆の元経度格子は日付変更線からわずかにずれています。総面積を保存し、帯内一様の面積配分で正規の30秒帯へ移します。±180°の外側部分は反対側へ折り返します。変換前後の総量一致を検証します。
