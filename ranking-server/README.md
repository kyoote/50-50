# ランキングの接続

1. 保存先のスプレッドシートを開き、「拡張機能 → Apps Script」を選びます。
2. Code.gs をこのフォルダーの Code.gs の内容に置き換えます。
3. HTMLファイルを追加して名前を Bridge にし、Bridge.html の内容を貼り付けます。
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」を選択します。
5. 実行するユーザーは「自分」、アクセスできるユーザーは「全員」にして公開します。Googleの権限確認は所有者本人が行います。
6. 表示された /exec で終わるURLを ranking.js の ENDPOINT に設定し、GitHubへ反映します。

シートの共有は制限付きのままで構いません。Rankingというタブを自動作成します。コードは既存のほかのタブを変更しません。匿名の閲覧者には名前とスコアだけを返します。

日本・世界・ランダム別に上位10件。同点は先に記録した人が先。同じブラウザーの識別情報ごとに最高得点だけ保存し、記録更新時の名前を使用します。ブラウザーデータを消した場合や別端末では別プレイヤーになります。名前は公開されます。

これはカジュアルなランキングです。得点の範囲・名前・モードを検証しますが、クライアントから送られた得点を保存するため改ざんを完全には防げません。賞金や厳密な競技向けではありません。大量アクセスにはApps Scriptの利用上限があります。

公開URLを設定するまでは準備中と表示し、登録を無効にします。接続後、別ブラウザーから順位を閲覧できること、スコア更新、モード切替を確認してください。Apps Scriptの更新時はデプロイのバージョンも更新します。
